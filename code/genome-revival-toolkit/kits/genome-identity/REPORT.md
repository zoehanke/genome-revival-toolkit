## 实现类

三个动作分别解析交接文件、比较明确区域、分析引物对。做事逻辑位于
capabilities/operations.py，模板只声明步骤，运行与记录继续走共享底盘。
旧版各类扩增、质量、区分状态并为规格指定的三种领域状态；旧流程、手工
埋点、格式化摘要和旧交接协议不保留。旧范围规则并入能力边界与未验证清单，
没有另建科学规则表或继承旧 verified 标记。

负例实际执行：相同长度不可区分；重复位点保留多个产物并报告无法确定；
环状起点上的引物被正确搜索；参考哈希不符中止。还检查了无产物、参考反向、
材料与文件错绑、交接里的引物不符及区域越界。标准库校核器也确实拒绝了
故意写成 1299 bp 的假结果表。

移植统计：旧 workflow.py 161 行、handoff.py 38 行；新运行文件 281 行，包含
声明与严格内联模式。只是不同职责的清单，不以行数宣称代码缩减。旧七个外部
项目模块依赖已去掉；新代码仅依赖标准库与两个公开边界。详细函数跨度和旧
结构耦合见 MIGRATION-LOG.md 本任务章节及 tests/evidence/s5b/inventory.json。

交接格式一致性：只读检查其他任务当前声明，合成输入符合 Construct 输出模式，
预期表符合 Revival Evidence 输入模式；固定 schema 字符串、引物 id 二元数组和
产物个数均一致。原始结果在 tests/evidence/s5b/interop.json。这只是模式一致性，
没有执行三 Kit 联合运行，没有替其他任务声明已审核。

临时默认四项均在 QUESTIONS.md 登记并在代码标注：区域比较采用明确区间和
单位代价编辑距离；多产物保守标无法确定；无交接时使用固定端口名作背景 id；
双方向 PCR 的去重与区域距离算法暂留本 Kit，等待是否上移共享层的决定。

传播搜索：本 Kit 运行文件和声明没有旧 schema_version、旧区分状态、
