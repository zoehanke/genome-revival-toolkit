## 规则与独立预期

原行为：没有通过的对照时，预测有带而报告阴性仍被判作矛盾，无法排除反应失败。
用户于 2026-10-17 决定：完整阳性可指出局部反证；阴性必须有报告通过的对照才可据以指出矛盾。
这只收紧所报记录与局部预测的比较，不认证实验或基因型。

实现只把已有观察字段 `result` 带入规则事实，同一张规则表按其 positive／negative 区分。
没有新输入字段、模式、状态、命令或判断引擎。阴性缺对照理由明确写出可能反应失败。
对照不确定仍单列在已有 unverified 项；阳性理由不混入该说明。

预期状态均来自任务表的构造。80 bp 由 20 + 40 + 20 的已定布局产生；
重复反向位点构成两个产物 80／131 bp；纯 C 的对照没有完整引物位点。
这些答案在调用 Kit 之前确定，没有用 Kit 输出生成验收答案。
独立校核器仅增加原始 result 事实，仍使用标准库、不导入 Core/Kit；另用手改错误报告确认它会拒绝假矛盾。
